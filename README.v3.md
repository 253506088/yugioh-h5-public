# 游戏王 · 决斗之境 V3

**11套预设、204张可组卡卡片、9种Link怪兽。** 新增珠泪哀歌族与连接召唤，沿用绿色与金色的决斗场、单HTML、组卡工坊和原版卡图在线加载。

双击 **index.html** 即可游玩，成品约630KB。所有游戏脚本、样式、音效、卡背都在这一份HTML中。游戏逻辑可以离线运行；原版卡图按英文原名从YGOPRODeck联网取得，失败时保留可读文字卡面。

## 新增内容

- 连接召唤：素材可按1或自身Link值计数，合计精确满足目标，并检查数量、名称、属性、效果怪兽等条件。
- 两个共享额外怪兽区，可选择可用的一侧；素材离场后会重新检查箭头与合法区域。
- 连接箭头、双方朝向、互相连接、Extra Link。点击场上的Link可看到所指向的区域。
- Link没有等级、阶级或守备力，只能表侧攻击；复活Link和从额外召唤Link使用不同的位置规则。
- 表侧额外灵摆可以使用Link箭头指向的主怪兽区，支持同时召回多只。
- 珠泪的效果送墓、洗回卡组底部融合、同时诱发、同名使用限制，以及I：P对方回合连接等战术。
- 旧牌组、所有卡片与新增Link可自由混合组卡；V1／V2存档会迁移到V3。

## 珠泪预设

在「新的决斗」中选择 **珠泪 · 壹世坏的回响**。珠泪是融合为核心的系列，这副构筑同时使用Link展开与干扰。

主卡组40张：20怪兽、13魔法、7陷阱。额外15张：6张珠泪融合、1张深渊的潜伏者、8张Link。

| 路线 | 组合 |
| --- | --- |
| 初动融合 | 雷诺哈特或绝海之马将珠泪人鱼送墓，包含该墓地卡把素材放回卡组底部，融合水仙女人鱼 |
| 水仙＋梅洛 | 水仙特殊召唤梅洛，再把自己送墓；两张卡分别发动堆墓5张和3张 |
| 融合与连接 | 两只不同名怪兽连接交织绵羊，将融合怪兽召唤到箭头位置，再复活低星怪兽 |
| 对方回合干扰 | I：P使用自身与其他怪兽连接独角兽；连接出的怪兽取得对方效果破坏抗性 |
| 终结路线 | 访问码使用Link素材提高攻击力，除外不同属性Link破坏场面；神弓处理怪兽效果 |

额外的8张Link：I：P、交织绵羊、梦幻崩影·凤凰、梦幻崩影·独角兽、暗灵使达克、清冽之水灵使艾莉娅、召命之神弓、访问码语者。连接栗子球另加入公共牌库，供自建卡组使用。

其余预设仍可选择：青眼、黑魔术、E·HERO、黑羽、废品／同调士、希望皇、机壳、艾克佐迪亚、电子龙、水晶机巧。

## 操作

| 操作 | 方式 |
| --- | --- |
| 查看合法行动 | 点击手牌或场上卡片 |
| 连接召唤 | 点击「连接召唤」，选择Link、素材和召唤区域 |
| 查看箭头 | 点击场上的Link，高亮区域与连线显示指向；不同颜色表示互相连接 |
| 同调／超量 | 从「额外召唤」选择目标、素材、表示和区域 |
| 珠泪融合 | 满足效果送墓条件后在诱发窗口发动；素材中有标注「必选」的墓地触发卡 |
| 连锁 | 选择可发动的响应；同时诱发按点选顺序组成连锁，逆序结算 |
| 自建牌组 | 在组卡工坊从空白或预设开始；保存、复制、撤销、导入导出后可直接出战 |
| 手机组卡 | 使用「牌库／当前构筑」切换，＋／−调整数量 |
| 快捷键 | Space切阶段，E结束回合，1—9选手牌，Esc关闭／取消，M音效，F全屏 |

连接、同调等作为素材送墓属于规则处理，不会触发珠泪“被效果送墓”的融合。丢弃代价与回合弃牌也不算效果送墓。已发动的墓地融合若失去必须使用的触发卡，例如被异次元乌鸦先除外，就不会继续融合。

游戏采用自由构筑，不使用赛事禁限卡表，保留了水仙等卡片。不能把本作当作完整官方裁定模拟器；实现范围以收录卡片与游戏内文字为准，没有仪式及未收录卡片的规则。

## 开发与验证

重新构建需要Node.js 18或更新版本，不需要安装游戏运行依赖。

~~~sh
node scripts/build.mjs
node scripts/serve.mjs
~~~

预览地址：http://127.0.0.1:4173/ 。新构建会写入根目录index.html，并在output/v3-builds中归档。

~~~sh
node --test tests/engine.test.cjs tests/v2-core.test.cjs tests/v2-regression.test.cjs tests/v3-rules.test.cjs
node tests/v3-simulation.cjs
node tests/v2-mixed-simulation.cjs
node tests/v3-browser.cjs
node scripts/verify-delivery.mjs
~~~

浏览器测试使用Playwright与已安装的Edge，可通过DUEL_BROWSER指定其他Chromium可执行文件。测试网络仅使用受控原图响应，不联系真实图源。迁移脚本保留供审阅，不属于日常构建步骤，后续应直接维护源文件。
