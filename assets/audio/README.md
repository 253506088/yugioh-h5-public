# 动画配乐

`manifest.json` 记录十首指定曲目的场景、Internet Archive 来源页、音频 URL、文件大小和 SHA-256。

```powershell
npm.cmd run audio:collect
npm.cmd run build
```

采集脚本复用校验通过的本地文件，检查音频格式后写入本目录。音频文件不提交到 Git；构建时自动内嵌已下载文件，缺失时保留在线来源。

战斗的六首曲目使用随机播放队列，每轮各播放一次，轮次交界避免连续重复。其余场景循环对应曲目。配乐和战斗音效有独立开关、独立音量；浏览器首次播放需要用户与页面交互。

曲名和音源属于相应原声作品；下载清单保留用于核对来源，项目代码许可证不改变音乐的权属。
