# 卡面素材说明

V2 的卡片插画通过浏览器在线读取 YGOPRODeck，由英文原名校验后使用原版裁切卡图。用户已允许联网加载图片；游戏规则与界面仍独立内嵌在一个 HTML 中。离线时显示中性文字卡面。可选的本地原图内嵌方式见 official/README.md。

以下为保留的 V1 素材记录。V2 仅使用其卡背，不再用演绎插画代替原版卡图。

本目录的所有 SVG 均由 scripts/generate-art.mjs 本地生成，保留完整可编辑路径。没有使用网络下载的原版卡图。

角色、卡牌名称与世界观致敬高桥和希创作的《游戏王》；本项目为非官方学习与同人演示。矢量插画是为本项目重新绘制的风格化演绎。
