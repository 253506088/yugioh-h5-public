# 原版卡图

当前版本按用户授权，在浏览器中通过 YGOPRODeck Card API 的英文原名匹配卡图，校验返回名称与图片域名，缓存图片地址。游戏逻辑不依赖网络。关闭在线卡图或联网失败时使用中性的文字占位卡面。

如果已有合法获得的本地原版卡图，可以按 `src/expansion-cards.js` 中的内部卡片 ID 命名为 `.jpg`、`.png` 或 `.webp` 放入本目录。构建器会将其内嵌到最终 HTML，优先于在线资源。请使用与卡名对应的裁切卡图，勿混用其他卡片。

V1 的演绎插画仍完整保存在 `assets/art` 和 `output/v1-baseline`，V2 不用其替代原图。
