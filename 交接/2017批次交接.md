## 规则边界与修复

- Link 导入保留连接值、箭头、数量、系列、种族、全部属性／包含属性、调整、通常／效果／反转、等级上限、额外来源及组内要求；未知语法报错。
- 新语法包括扎克的四种龙族素材、泥龙王的同属性异种族、不同属性六武众、双调整融合、暗属性灵摆非调整；复合灵摆不丢失额外类型。
- 上级召唤菜单来自完整合法组合，永续魔陷可选，但不能偷用于通常盖放。剑皇保存实际祭品卡种，并区分技能抽取在先／在后。
- 机器人只选合法素材组。杂食龙按可召唤等级生成必要样例，避免枚举大量墓地子集。
- 曼珠诗华不能在同一连锁重复公开同一张卡；下一条连锁仍允许合法换场。
- 盆回原盖放场地可以发动，其余场地受限制；拮抗由对方选择，按玩家必须执行的除外处理，不错误套用怪兽效果免疫。
- 持续魔陷需要仍在场才能适用发动的效果；旋风连锁破坏 SPYRAL Resort 后不能继续检索。
- 墓地代价、延迟操作、资源移动和生命值均使用统一接口，状态可以 JSON 往返。

本作适配：失落世界／代理龙的可选破坏代替自动选既定优先级替代卡；光之舞台封锁的盖卡在结束阶段未发动则自动送墓；防火龙使用现行勘误。说明均有中英日文本并在详情显示。
