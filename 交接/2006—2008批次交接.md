## 文件与规则

新规则按 `effects-2006*`、`effects-2007*`、`effects-2008*` 分册，跨年收尾与复制登记位于 `src/effects-year-final.js`。CommonJS 从 `advanced-effects.js` 加载；浏览器的同一顺序由 `scripts/build.mjs` 显式内嵌。九套预设在 `src/year-decks.js`，通过 `early-decks.js` 接入。三语界面增量为 `src/i18n-years-gx.js`。

`scripts/lib/card-materials.mjs` 提供明确的融合／同调素材语法：指定名字、系列、种族、属性、最低等级、可变数量、指定调整与非调整条件。未知素材格式会报错，不能静默导入成不限素材。NEX 专属融合、神新宇侠、多系列融合、通常调整及二重类型有独立标记。幻神兽族也加入导入映射。

主要机制包括：

- 除外替代送墓、实际送墓代价、二重召唤及重置、仪式卡组素材、接触融合、未来融合的两个准备阶段、连锁结束事件。
- 命运英雄、六武众、外星人、电子暗黑、宝玉兽的后场转换、剑斗兽换人／登场、云魔物、毒蛇、邪心英雄和早期同调。
- 光道送墓与暗武装龙的精确墓地条件、念动力展开、同调素材限制、爆裂模式、变形斗士、自然／次世代／魔轰神等本年系列规则。
- 所有选择、延期和复制存档只携带 ID 与 JSON 数据，存档版本仍为 3。正式入口仍为根目录 `index.html`。

## 运行检查发现并修复的问题

- 宝玉兽进入后场需要合法的独立状态标记，不能伪装为怪兽装备；破坏后的可选去向可以存档恢复。
- 额外卡组中的接触融合动作需要被 `available()` 枚举；本次新增两条加载链都实际提供这一动作。
- 无效判断出现递归时使用临时重入保护，不将保护状态写进存档；暗黑新宇侠以自身为对象仍能终止。
- 灵活数量的破坏目标不会为了凑到最大数量而让 AI 把自己的凯撒一起破坏；已满足最小数量时停止选取负收益目标。
- 发动次数、通常召唤统计等不是收益。机器人投影排除这些记录字段，继续保留旧版“不浪费重复保护”的行为。
- 寒波期间不再把非法盖放提供给玩家和 AI；光枪龙没有对方卡片时，不再出现最少 1、最多 0 的弃牌窗口。
- 特殊召唤必须是怪兽或已有合法陷阱怪兽状态。系列名包含「变形斗士」的场地／魔法不会被当成可苏生怪兽，也不能用发动卡自己支付其怪兽代价。
- 融合、同调、仪式等怪兽发动效果统一标为怪兽效果，使战车等反击卡能识别；不会把同调怪兽的效果误记成一种独立魔法类型。
- Miniaturize 的降星处理保留 Link／超量／临时无等级怪兽的零等级，没有对整个卡池统一强制最少 1 星。
- 追加抽卡结果测试发现旧卡 `Muko` 将两个缺省值相等误判成正在处理自身连锁，可能让普通抽卡直接丢弃。现在要求确有其记录的连锁，普通抽卡与卡片额外抽卡保持正常。

## 验证口径

最终数量及运行结果见同批 `docs/verification-2006-2008.md`。该文件在最终构建与测试完成后生成，不能把开发中的首轮失败日志当作最终回执。

`gx-rules.test.cjs` 使用真实 `act()`、真实区域、LP、素材和 snapshot/restore 检查关键行为。`gx-sweep.test.cjs` 对 1,257 张来源卡逐张建立有资源的规则夹具，提供合法发动机会，执行真实阶段、攻击和离场操作并检查状态守恒。扫描中的初始怪兽允许直接安排到指定位置；它不是每张卡的全部召唤手续、所有分支或每个 UI 操作都测试过的证明。专项场景另测真实召唤代价。

`gx-simulation.cjs` 将九套新牌分别与青眼、黑魔术师、HERO、守墓交换先后手，共 72 场，并运行含全部九套的 16 人赛事；决赛逐步回放比较最终快照。`gx-browser.cjs` 检查三语年度筛选、九套预设、真实观战、二重召唤按钮、刷新恢复和手机布局。

## 本作适配边界

本批延续既有独立规则引擎的适配口径。以下属于明确边界，不能宣传为完整官方裁定模拟：

- 钻石人的延迟复制覆盖登记的常用魔法白名单；依赖额外复杂代价数据的魔法暂不复制。
- 黑豹、混沌幻影和神新宇侠复制已登记的主动效果；独立诱发／被动效果不在该复制范围。
- 部分 A／雾指示物使用区域顺序分配；部分复数素材、硬币选择与紧急同调采用自动选择。具体注释保存在对应 `implementationNote`。
- 批量同时特殊召唤、多来源持续无效的优先级、伤害步骤中的全部“时／场合”差异、完整历史卡文和 Match 胜利，仍需另行专题审计。
- 数据身份、年度候选、三语完整、规则登记、运行扫描与专项测试是独立维度。本批报告不将这些维度混成“所有官方裁定均已认证”。
