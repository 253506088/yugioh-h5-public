## 实现入口与跨年修正

`src/effects-2015.js` 及 30 个分册覆盖灵摆／超量灵摆、EMEm、龙剑士、影灵衣支援、彼岸、帝王、DD、超量、疾行机人与PSY骨架、幻影骑士团、魔玩具、幻奏、真红眼、卡通、传说之龙、急袭猛禽、超重武者、不知火、破坏剑等。分册顺序同时登记在主文件的 Node require 列表与 `scripts/build.mjs`，全部早于天命规则层。

- 导入器保留超量灵摆的超量类型、阶级、刻度与两段文本；无灵摆效果卡可使用单段怪兽文本。素材语法新增复合种族／属性、灵摆、不同名和传说之龙手续。
- 球体形可以使用一侧场上的三只怪兽，上级召唤到该侧，消耗真正召唤者的通常召唤次数。不能混用两侧祭品或通常盖放。
- 墓地代价通过统一 `graveCostAllowed` 检查，灵魂解放及应战的G不能让“必须送到墓地”的代价被错误支付。
- 暂时除外返回不增加特殊召唤次数，计时、控制者、表示形式和 generation 均可 JSON 恢复。
- 效果复制器登记年度主动／快速效果，包含传说的骑士 赫谟与狱火机 十进管的适配。
- 全库 CDB 的 alias 同时包含别画和规则同名。导入器现只折叠名称相同的别画，置换融合和融合保留各自身份与密码；传说之都／海也不会混为同一张卡。
- 绑定式无效判断增加重入保护，修复古神 哈斯塔、拘束臂等递归问题；图鉴展示逐卡适配说明。

## 复现与提交

使用 Node 22.13 以上。本机命令为 `C:\nvm\v22.17.0\node.exe`，默认 PATH 中的旧 Node 不适用。

`npm run cards:import` → `npm run locales:sync` → `npm run cards:catalog` → `npm run decks:chronicle` → `npm run build`。验证入口是 `npm run test:2015`、`npm run test:archetypes`、`npm test`、`test:2015:browser` 以及年度／天命规则／PVP 脚本。最终结果见 [验收记录](../docs/verification-2015.md)。
