## 复核修复与后续约定

小夜的组合目标必须在目标保护过滤后同步更新 `sets` 和 `candidates`。此前纯爱妖精街道保护的怪兽从界面候选中移除了，AI 的组合仍包含它，会在真实整局中提交非法选择。现在无合法组合时禁止发动，合法组合与候选保持一致；案例32完整重放通过。

共享额外怪兽区的 `find().index` 已是物理区域编号，不能再次传入接收相对区域名称的 `extraSlot()`。已修复拉岑的列判断，并用双方、两个额外区的四个真实破坏场景回归。

三战的发动历史必须保留在真实存档中，但不能单独算作 AI 边际收益。`ai-marginal.js` 仅在结果比较时排除两个历史字段，实际三战许可仍按真实发动生效。既有卡利古拉空效果回归与三战实际发动回归共同验证。

`cardAllowsSetActivation` 是救援王牌的卡片许可，与天命盖放许可分开。场地魔法可通过统一 `move` 盖回场地区域，替换旧场地时先按规则送墓；卡片发动允许从里侧场地区域开始。素材限制即使对应卡片 pending 或效果无效也保留。

供应方 Ace★Spades Speculation 的真实规范链接含 Unicode 字母，已实际访问核对到对应卡片页。百科检查与导入器统一校验解码后的字母／数字／连字符路径，同时保持 HTTPS、固定域名、无凭证／查询／片段限制，未修改正式供应方原件。

正式 HTML 沿用内嵌 gzip 脚本，保留821张卡图、11张卡框和10首本地音乐；需支持 DecompressionStream。图形与音频原件仍留本机，干净克隆可离线重建卡片数据；不能把依赖本机媒体的逐字节成品重建称为无媒体缓存重建。

最终测试、成品大小／哈希与复现命令见 [2023验证记录](../docs/verification-2023.md)。正式源码、数据、测试、压缩卡图、文档和 `index.html` 提交；研究网页、原图、日志、截图、重放、失败现场、临时构建及提交草稿由 `.gitignore` 排除。实际提交号与远端同步以 Git 记录为准。
