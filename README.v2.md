# 游戏王 · 决斗之境 V2

向高桥和希的《游戏王》致敬的单文件卡牌决斗游戏。现在包含 **10 套预设、176 张可组卡卡片**，支持融合、同调、超量、灵摆，以及可保存、自建和导入导出的组卡工坊。

## 直接游玩

双击本目录的 **index.html** 即可，建议使用近期的 Edge、Chrome、Firefox 或 Safari。最终成品约 550 KB，CSS、游戏逻辑、效果数据、音效和卡背都已编译到这一个 HTML 中，可以单独复制。

**游戏逻辑可以离线运行；原版卡图需要联网。** 卡图按英文原名从 YGOPRODeck 请求，校验返回卡名与图像域名后显示。第一次打开会逐步载入；图源不可达时保留可阅读的文字卡面，召唤、效果与组卡仍正常工作。设置中可以关闭原图联网，也可以点击页头的原图状态重试。

对局、设置、自建卡组和编辑草稿保存在当前浏览器本地。刷新可继续对局；换浏览器或移动 HTML 可能不会携带原存储，建议先导出自己的卡组。兼容旧版 V1 对局存档的迁移。

## 组卡工坊

1. 点击页头「组卡工坊」。可选择预设建立副本，也可以新建空白卡组。
2. 用系列、卡片种类、调整筛选，或搜索中文名、英文名、效果。点击卡片查看完整说明，使用 ＋／− 调整数量。
3. 主卡组须40—60张，额外卡组0—15张，同名卡合计最多3张。融合、同调、超量怪兽自动进入额外卡组；衍生物不能编入。界面实时显示问题。
4. 合法构筑可以「保存卡组」或「保存并出战」。支持复制、撤销／重做、删除已保存卡组、JSON导入和导出。

全部卡片已经解锁，不采用赛事禁限卡表。未完成的构筑仍会保留为草稿；删除一个已保存卡组不会删除当前编辑草稿，也不会破坏正在进行的对局。

## 对战操作

| 操作 | 方式 |
| --- | --- |
| 召唤、盖放、效果 | 点击自己的卡牌，菜单只列出当前合法行动 |
| 同调／超量 | 点击「额外召唤」，选择怪兽、素材及攻击／守备表示 |
| 融合 | 发动融合类魔法或效果，依次选择融合怪兽、素材与表示 |
| 灵摆 | 把灵摆卡放入左／右刻度；点击「灵摆召唤」选择怪兽与表示 |
| 素材条件 | 选择窗口实时校验，可点选已计算好的合法组合 |
| 超量素材 | 点击超量怪兽，再选择查看素材；发动效果时选择移除的素材 |
| 墓地／除外效果 | 点击对应卡堆，可用效果显示在卡片下方 |
| 攻击 | 进入战斗阶段，点击自己的怪兽选择攻击，再点击敌方怪兽 |
| 连锁响应 | 选择效果并确认发动，或点击「不连锁」 |
| 多个同时诱发 | 依次点选决定连锁顺序；后选的效果先结算 |
| 阶段／回合 | 右侧按钮或手机底部控制；Space切换阶段，E结束回合 |
| 快捷操作 | 数字1—9选手牌，Esc取消未提交选择，M音效，F全屏 |

场地提供5个主怪兽区、5个魔法陷阱区、每方1个额外怪兽区、场地区、墓地与除外区。灵摆区使用最左和最右魔陷区。融合、同调、超量也能使用主怪兽区；从表侧额外卡组灵摆召唤的怪兽只能使用空余的本方额外怪兽区。

引擎保存超量素材、原持有者、装备关系、效果无效、每回合使用次数、召唤限制和连锁中的选择。连锁逆序结算，破坏效果来源不会自动等于无效效果；已离场再返回的卡不会被旧目标继续追踪。支持战斗卷回、伤害计算时响应、艾克佐迪亚胜利与平局。

## 规则范围

本作是围绕已收录卡片制作的独立同人规则实现，**并非完整的 OCG／TCG 裁判模拟器**。以界面显示的中文效果为执行规则；完整官方裁定与个别时点仍可能存在差异。使用每方一个额外怪兽区的布局；没有连接、仪式、侧卡组、赛事禁限卡表及未收录卡片。

抽卡与准备阶段自动处理；不同召唤方式、快速效果、同时诱发和连锁已实现。按卡片指定的表示执行特殊召唤；融合、直接同调／超量与灵摆的选择窗口可选择攻击或守备表示。

原版卡图的实际网络连通性未在开发环境核验：内置浏览器的预览请求被自动审批服务拒绝，审批模型接口返回HTTP 404。本地下载未继续重试或绕过。在线加载已通过受控数据测试，包括名称匹配、域名校验、图片失败恢复和离线回退。

## 重新构建与验证

构建需要 Node.js 18 或更新版本，游戏成品本身不需要安装任何依赖。

~~~sh
node scripts/build.mjs
node scripts/serve.mjs
~~~

本地预览地址是 http://127.0.0.1:4173/ 。构建器只合并本地源码；联网仅用于玩家打开游戏后的可选卡图。若已有原版裁切卡图，按内部卡片ID命名放入 assets/official，构建时会优先内嵌，详见该目录说明。

~~~sh
node --test tests/engine.test.cjs tests/v2-core.test.cjs tests/v2-regression.test.cjs
node tests/v2-simulation.cjs
node tests/v2-mixed-simulation.cjs
node tests/v2-browser.cjs
~~~

预设对局默认20场，可通过环境变量 DUEL_MATCHES 设置为100。浏览器检查使用 Playwright 和已安装的 Edge，DUEL_BROWSER 可指定其他 Chromium 可执行文件。这些仅供开发验证；浏览器测试不联系真实图源，使用本地受控响应。

create-v2-ui.mjs 是保留的迁移中间产物，不属于日常构建步骤。后续维护请直接修改 game-v2.js；不要重新运行迁移脚本覆盖已修订的UI。
