# 可核验的历史原牌表

`world-champions.json` 保存手工从公开原牌表逐格核对的结构化清单，不是模型按记忆生成的牌表，也不是本作改编预设。

每条必须包含年份、冠军、赛事页 URL、原牌表图片 URL、图片 SHA-256、人工核对日期，以及主/额外/副卡的名称、数量、密码。当前 2010 条目依据 Road of the King 公开记录：Galileo De Obaldia，Frog FTK，41/15/15。牌表图包含来源署名，赛事页还记录了副卡最后一张 Treacherous Trap Hole 的作者核正。

新增年份时：

1. 实际读取赛事页，确认是需要的赛事与名次，不能仅相信搜索结果标题。
2. 获取该名次的原图，逐格核对名称/数量/分区，用全库三语名录核对密码；保存图片哈希及核对日期。
3. 新增结构化记录和对应回归测试。图片原件、下载页面只放 `output/`，不要混入发布包。
4. 验证 `server/championship-search.mjs` 能在运行时重新读取页面、核对冠军及同一张原图的哈希；哈希变动必须重新人工确认，不能简单替换哈希以放行。
5. 不把无法核实的名单、普通投稿或本作适配构筑标成冠军原版。对暂未实现或当前卡池未收录的卡，保留原版记录并如实显示状态。

此目录需要进入 Git 和 Docker 镜像；源图片不需要。网络访问仍受公网地址、大小、超时限制，不接受客户端任意指定的赛事 URL。
