# 决斗体验升级

从项目根目录运行 `npm run build` 后，双击 `index.html`，或运行 `npm start` 并访问 <http://127.0.0.1:4173/>。

## 本次功能

| 需求 | 操作与行为 |
| --- | --- |
| 调节字体 | 设置 → 阅读与显示，支持 90%—150%，每档 5%。桌面右上角也有 A− / A＋。字号自动保存，卡片详情和操作文字同步调整。 |
| 图鉴与工坊分页 | 每页可选 12、24、48、96 张，支持直接输入页码。分页位于独立的底部区域，滚动卡片时始终可用；图鉴和工坊分别保存页大小。 |
| 主界面与一屏决斗 | 首页集中提供开始／继续决斗、卡牌图鉴、卡组工坊和玩法指南。点击左上角标志返回首页。战场按窗口高度排布，包含双方 LP、四排主区域、额外怪兽区、阶段和手牌。 |
| 分场景 BGM | 十首指定配乐均有本地音源。战斗音乐以六首为一轮随机排列，每轮不重播，轮次交界也不会连续播放同一首。查看图鉴、工坊或指南后返回，会继续先前的战斗配乐进度。 |
| 卡背与卡框 | 使用原版旋涡卡背；通常、效果、融合、同调、超量、灵摆、仪式、Link、魔法、陷阱、衍生物分别显示对应卡框。设置可切换经典卡框／全图卡面。 |
| 连锁数字和异常提示 | 双方的发动共用一组连锁编号。无效、目标丢失、需要在场的来源离场分别提示，并在可追溯时标明是哪一环造成。 |
| 连锁演出 | 构筑时显示双方卡片、归属、编号及连接效果；结算时从大号到小号逐环突出显示，1 最后处理。战场上的 ∞ 按钮打开记录，可回放已发生的连锁。 |
| 查看战局 | 响应或素材选择面板中的“查看战局”会保留决策和已选项目。可查看公开卡片、墓地、除外区、记录，再点击“返回选择”继续。关闭面板或按 Esc 同样保留机会。 |
| 减少响应打断 | 默认 AUTO 保留对方发动、召唤和攻击等关键时机，略过泛用陷阱对普通盖放、开放时点及自己连锁的询问。ON 显示每个合法窗口，OFF 自动放弃可选快速响应；强制效果和已发动效果的选择仍需完成。 |
| 回合数 | 战斗顶部始终显示当前回合、行动方及阶段；手机底部提供阶段推进和结束回合操作。 |

## 小屏与显示

- 手牌较多时只滚动手牌区域，战场宽度保持不变。横屏手机把手牌放到右侧，保留更多场地高度。
- 手机及较矮窗口的工坊可展开“筛选与搜索”，设好条件后点击“显示筛选结果”。卡片与底部分页拥有独立空间。
- 窄屏英文阶段条使用 DP / SP / M1 / BP / M2 / EP；完整阶段仍显示在回合信息中。
- 字号、语言、页大小、卡面样式和音量都保存在本机。对局存档与工坊草稿分别保存；刷新后从首页继续。
- “减少动态效果”关闭弹窗移动和缩放，连锁的关键结果仍保留阅读时间，也可以主动跳过演出。

音乐播放需要先与页面交互一次。首页左下角、桌面战斗记录面板下方的配乐条可以开关 BGM、打开音乐设置和切换下一首战斗曲目；小屏通过设置管理配乐。设置中的配乐音量与战斗音效音量独立；关闭音效不会关闭音乐。

下载的音频与原始大图已加入 `.gitignore`。源码仓库包含来源清单和小型界面资源；需要重新取得本地音乐与预设／连锁示例卡图时运行：

```powershell
npm.cmd run audio:collect
npm.cmd run art:experience
npm.cmd run build
```

常规构建把已有音乐、卡背、卡框和已有卡图嵌入单 HTML。缺少本地音乐时使用清单中的在线音源；缺少卡图时保留可读卡面，并按用户设置补充在线卡图。

## 验证

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run build:no-art
npm.cmd run test:browser
npm.cmd run test:experience
```

`test:experience` 包含连锁规则与归因、随机播放、标准和小屏布局、150% 字号下的三语界面、20 张手牌、固定分页、刷新偏好、查看战局、真实三环连锁与十首音频的浏览器验证。截图和 JSON 报告保存在 `output/experience-*/`，不提交到 Git。

浏览器测试默认使用本机 Edge，也可通过 `DUEL_BROWSER` 指定浏览器可执行文件。规则测试不需要浏览器；浏览器验证拦截外部请求，音频从构建内嵌资源解码。
