# AI 卡组导入

新增「联网组卡」标签：根据自然语言需求检索真实公开牌表，再推荐原版或调整成当前卡池可用的构筑。流程、来源与费用边界见 [根据描述联网组卡](ai-deck-research.md)。

在「组卡工坊 → AI 导入」中粘贴清单、选择 YDK / JSON / TXT 文件、粘贴 YDKe 链接或上传最多四张图片。文本支持 `3 青眼白龙`、`3x青眼白龙`、`青眼白龙 ×3`，以及中英日分区标题。结构化输入完全离线，不需要 API 令牌。

文章、图片使用「设置 → AI 助手」里配置的模型。支持 OpenAI Responses、Chat Completions 与 Anthropic Messages。地址填主机或路径前缀，末尾已有 `/v1` 时不会重复添加。默认 Responses；DeepSeek 预设使用 `https://api.deepseek.com`、Chat Completions、`deepseek-flash`。密钥必须自行填写。图片需要模型本身支持视觉；选择 PNG、JPG、WebP 后会自动缩放到最长边 1568 像素并压缩为 JPEG。

模型只抄录卡名、数量和分区，不接收本作卡池、不提供内部 ID。本地四级索引优先使用权威数据库三语名，结合密码、别画 alias、别名和模糊匹配。14,981 条全库名录用于区分「未收录」和「无法识别」；名称相同的别画折叠为主号；规则同名 alias（如置换融合与融合、传说之都与海）保留不同物理卡身份。当前已收录至2015年，7,486张卡可离线识别。「7」这类纯数字卡名与 YDK 密码通过输入类型区分。

结果支持多副卡组切换、逐卡候选确认、手动改名重试、未收录卡需求清单。可用卡进入草稿；待实现、未收录和未确认卡保留在备注，副卡组默认也仅保留在备注，可点击或拖动移入构筑。重复同名合并超过三张时仅保留三张并提示。`DuelDecks.analyze` 检查主卡组 40–60、额外 ≤15、类型和同名上限；不合法也能先载入工坊继续编辑，保存时必须通过校验。载入可撤销，原有卡组不会被覆盖。

第二轮识别默认关闭。开启后仅将第一轮仍为 unknown 的名称发送一次，返回名称重新经过本地精确匹配；即使命中，也要求用户确认。失败时保留第一轮结果。清单每区最多 400 条、每次合计最多 2400 条，长清单分批匹配，取消按钮保持可用。

令牌保存在本浏览器 `duel-sanctuary-ai-provider-v1`，不会进入卡组导出、存档、联机投影或决斗记录。清除令牌立即更新存储。模型请求只包含本次输入；代理仅在请求头中接收令牌，不保存、不记录。浏览器直连受目标服务的 CORS 限制；网络错误会提示使用服务器代理。

## 服务器与网址

运行 `npm start` 后，页面会检测 `/api/ai/info`，开放服务器代理和网址输入。双击单文件 HTML、GitHub Pages 或 `npm run start:static` 都会显示静态降级提示，建议粘贴文字或截图。

- `POST /api/ai/complete`：仅接受本项目定义的抽取、第二轮识别和连接测试，复用相同协议适配器。浏览器令牌通过 `X-Duel-AI-Key` 发送。
- `POST /api/ai/fetch-url`：仅公开 HTTPS；DNS 全部解析结果必须为公网，并固定到实际 TLS 连接。最多三次重定向且逐次复检，15 秒超时，响应 ≤2 MB，仅 HTML/纯文本。保留表格与列表文字，去掉脚本、样式等。页面文字超过 60 KB 时截断并显示提示。
- `DUEL_AI_UPSTREAMS`：可选、逗号分隔的模型主机白名单；空值允许公网 HTTPS。此名单不作用于用户导入的网页。
- `DUEL_AI_DEFAULT_KEY`、`DUEL_AI_DEFAULT_URL`、`DUEL_AI_DEFAULT_MODEL`：同时设置才启用托管令牌。令牌绑定管理员指定的地址、协议、接口与模型，不会发往用户任意指定的站点。`DUEL_AI_DEFAULT_PROTOCOL` 默认 `openai`，`DUEL_AI_DEFAULT_ENDPOINT` 默认 `responses`。
- `DUEL_AI_HOURLY_LIMIT`：托管请求每 IP 每小时 30 次。全部路由另有限制：每 IP 每小时 120 次、同 IP 并发 2、全局并发 8。

Node 启动可用 `node --env-file=.env.local server/index.mjs`，`.env.local` 已忽略。Docker Compose 已转发这些变量，可通过部署机器的 `.env` 配置。反向代理后的 IP 信任规则沿用 PVP 配置，仅在后端不直接对公网暴露时启用信任代理。

## 构建与验证

```sh
npm run cards:catalog          # 从已提交的三语 .cdb 离线重建名录并核验 SHA-256
npm run build                  # 包含名录、别名及新界面的单文件 index.html
npm run test:ai-import:unit     # 假 fetch、真实卡池、解析器与本地服务器安全测试
npm run test:ai-import:browser  # 拦截模型网络，覆盖清单/图片/网页/三语/保存/取消
npm test                       # 含 AI 导入在内的项目回归
```

需 Node ≥22.13；浏览器测试默认 Windows Edge，可用 `DUEL_BROWSER` 指定 Chromium 路径。测试不访问真实模型。`DUEL_AI_TEST_PAGE` 可指定无图构建，但服务器浏览器测试仍使用根目录发布入口。

正式提交源码、测试、别名 JSON、生成的 `src/card-catalog.js`、文档与根目录 `index.html`。`output/ai-import/` 内截图、临时构建与接口测试报告只留本机。真实密钥不写入任何构建输入。

与设计稿的取舍：保留全部三种接口；副卡组不自动并入主卡；托管令牌可选且绑定接口；第二轮关闭；需求清单本地保存；全库名录内联；五张历史自有名维持原样，由权威名优先规则处理，避免扩大对现有规则和搜索的改动。

## 本次验证（2026-09-22）

- 全项目回归 5,713 项通过；收尾变更另经 27 项 AI 导入专项测试通过。
- 9 组浏览器流程通过：离线确认与撤销、配置及三语、模型多卡组保存/导出、YDK 别画与副卡组、图片压缩与手机布局、取消、第二轮及失败降级、不合法分区刷新保留、服务器网址输入；未捕获页面异常。
- 原有界面回归 3 组通过。其中牌组搜索测试还写死旧版 38 套预设，现改为读取当前牌组总量（43），保留筛选数量和搜索行为的断言。
- 三语名录离线重建逐字节一致；全卡池名称自检无歧义，仅保留设计稿已知的五组权威名优先覆盖。
- DeepSeek Flash 实际连接及自然语言清单抽取通过；确认其 JSON Schema 不兼容时的 JSON 模式降级，输出仍通过严格校验。真实结果正确识别青眼白龙、效果遮蒙者、希望皇霍普，灰流丽由本地判为未收录。模型图片流程用固定响应测试，不代表 DeepSeek 的视觉能力。
- 实测日志、截图与报告均在已忽略的 `output/ai-import/`；源码及发布 HTML 扫描未发现提供的真实令牌。
