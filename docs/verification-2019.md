## 对局与浏览器方法

年度对局使用正式五套预设，与2016青眼／十二兽交换先后手，并覆盖26条天命。第24个动作进行JSON恢复，终局从初始快照逐个动作重放，比较完整终局快照。四个分片保持原种子和案例编号。

赛事使用固定种子 `20191001`、64人名单、standard难度和生产行动／回合上限。`tests/tournament-parallel-helper.cjs` 只并行独立场次，实际调用生产 `Tournament.stepMatch`，按轮次屏障推进晋级，每场返回前核对完整重放，最后再恢复整个赛事存档。

浏览器直接打开正式 `index.html`，阻断外部HTTP请求。验证年度筛选、完整主／额外／副卡、三语身份状态、内嵌图、桌面和390×844手机布局，并通过真实控件操作羚羊、伽拉忒亚、Absorouter Dragon、仆从和尼比鲁。指示物选择在切换语言后仍保留；完成操作后检查实际引擎区域与数值。2018、2017兼容回归继续验证旧牌组流程。

## 重现命令

本机使用已有Node22：

```powershell
$env:Path = 'C:\nvm\v22.17.0;' + $env:Path
npm.cmd run cards:import
npm.cmd run locales:sync
npm.cmd run cards:catalog
npm.cmd run decks:chronicle
npm.cmd test
npm.cmd run test:2019
$env:DUEL_YEAR = '2019'
node --test tests/chronicle-sweep.test.cjs
Remove-Item Env:DUEL_YEAR
npm.cmd run test:2019:simulation
npm.cmd run test:2019:tournament
node tests/chronicle-simulation.cjs --quick
$env:DUEL_MIRROR = '0'
node tests/rule-modes-simulation.cjs
Remove-Item Env:DUEL_MIRROR
npm.cmd run build
npm.cmd run test:2019:browser
npm.cmd run test:2018:browser
npm.cmd run test:2017:browser
$env:DUEL_TEST_HTML = (Resolve-Path index.html).Path
node tests/rule-modes-browser.cjs
Remove-Item Env:DUEL_TEST_HTML
node scripts/build.mjs --out output/rollout-2019/rebuild/index.html
```

年度整局可设 `DUEL_SHARD=0..3` 分四份；编年quick可设 `DUEL_SHARDS=4` 与 `DUEL_SHARD=0..3`。本次统计均合并核对全部分片。效果登记不是正式裁定认证，逐卡适配与pending边界见[交接](../交接/2019批次交接.md)和[覆盖表](coverage-2019.md)。
