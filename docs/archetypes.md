# 系列归属：OCG 系列码与统一入口

2026-09-27，完成《系列本家识别问题修复方案》阶段二。阶段一随 2015 批次提交为 `db24145`。

## 数据与加载

`scripts/sync-locales.mjs --offline` 从已提交的日文 CDB 读取 `datas.setcode`，使用 BigInt 拆出四个 16 位码。来源固定为 `mycard/ygopro-database@ac5d8fb80465e74b33f3b4a294e3b22c02d743f2`，没有刷新上游数据库。自身系列码非空时优先自身；只有为空才沿 alias 查找，包含循环保护。

- `data/locales/cards.json`、`src/card-locales.js`：7,486 张可组卡的 `setcodes` 与 `setcodeSourceId`。
- `data/archetypes.json`：265 个登记项，其中 256 个系列码、8 个明确的卡名片段、1 个种族分类。
- `data/archetype-tokens.json`：固定数据库中的衍生物查表；`data/archetype-token-identities.json` 记录九个旧手工英文名称与真实数据库身份的对应，包含生成它们的卡密。
- `src/archetype-data.js`：生成的浏览器／Node 共用资料。
- `src/archetypes.js`：统一判定和兼容标签。Node 与单文件 HTML 都在卡片资料之后、全部效果模块之前加载。

运行时全部 **7,571 个身份（7,486 张可组卡＋85 种衍生物）**都有权威系列码数组。`[]` 表示数据库明确没有系列，不能退回英文名匹配。例如竹木废料生成的植物衍生物不属于废铁；旧手工英文名中的 Scrap 不再影响判定。九个衍生物身份对应逐一核对了原始名称、等级、攻击力、防御力和生成卡，不是系列归属例外。

## 效果代码

```js
D.inArchetype(card, 'Blackwing');
series(card, 'Blackwing'); // 年份公共 API，委托给同一入口
```

支持卡片定义、对局实例及内部卡片 ID。判定采用 `(s & 0xfff) === (code & 0xfff) && (s & code) === code`，包含子系列和规则视为本家的归属。卡种、等级、调整等卡面限制由调用方另外判断。

所有旧效果与引擎中的直接 `family` 比较已经迁移，包括同调调整、融合素材、上级召唤、升阶、战斗支援和 AI 评分。旧的 `family`、`families` 与标志位只保留兼容展示用途；`isFamily` 仍服务图鉴的主题合并分类。例如“废品／同调士”筛选可以包含两者，但废品系列的素材要求不会接受氮素同调士。

HERO／英豪、废铁／摩天楼、超量／XYZ-神龙炮、同调士／同调能量、进化系列等误认已修正；下位恶魔、女神的圣剑-鹰灵、对极英雄、Electric Virus、Steelswarm、兰斯洛特及传说之龙等归属由系列码认定。

系列归属不覆盖卡面限定：侵略之炎确实具有 Infestation 系列码，但它是怪兽，仍不能被只检索魔法／陷阱的入魔龙祖检索；世代之力也不能检索“超量士”等怪兽。守护者检索保留明列的五张排除卡。“洞”与“落穴”分别登记 0x89、0x4c；虫惑魔支援使用二者的并集。电子负载融合按融合素材是否列出电子龙判断，不能拿编辑器的电子龙主题分类代替素材条件。

## 非系列与未来维护

八个卡名片段是 Bujingi、Coach、Gorgonic、Mythic、Neo Space、Nitro、Obelisk Force、Sphinx；各自在登记表中写明匹配方式和原因。Psychic 是念动力族筛选。它们没有被伪造为独立 OCG 系列码。

只有未来没有数据库身份的自制卡，才允许使用登记项中明确的英文名兜底。当前正式卡池没有这种身份。新增系列必须登记，未知键会报错；新卡若缺系列数据，守卫测试失败。不要在效果分册中单独补 `series` 或依靠英文子串绕开入口。

素材卡名和系列是两种约束：具体卡名继续使用 `id`／`nameId` 与 `cardNameId`；系列用 `family`／`tunerFamily`／`series` 等已有元数据，最终统一调用系列码入口。动态改名不等于替换静态系列码。
