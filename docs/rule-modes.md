# 天命法则

每场决斗开局时，从 25 条法则中等概率抽取 1 条，整局对双方生效。法则属于游戏规则，不是卡片，不进入连锁，不能被无效、破坏或复制。经典模式不会启用这些规则。

## 进入方式

- 首页「天命法则」：浏览、分类筛选或搜索全部规则，再开始天命对局。
- 新的决斗：选择「经典规则／天命法则」，同时支持我对机器人、机器人对机器人。
- 死斗竞技场：在赛事设置中选择天命法则，每一场和每次重赛分别抽取。
- 联机房间：创建时选择天命法则，房间显示模式；开局后由服务器抽取，双方共享结果。快速匹配继续使用经典规则。

开局会短暂揭晓法则。战场上方始终显示当前法则，点击可查看全文和次数状态。苦肉按钮出现在规则栏和可用响应窗口；血祭召唤出现在相应手牌的行动菜单。属性克制模式选择攻击对象时，公开目标上会显示双方参与伤害计算的有效数值。悬赏怪兽显示「通缉犯」标记。当头炮的中心主怪兽区有高亮。

存档、重连、AI 推演和赛事录像都保留当前抽签及次数；「再来一场」重新随机。界面和规则说明支持中文、英文和日文，单 HTML 可离线游玩。

## 25 条法则与本作结算口径

| 法则 | 结算 |
| --- | --- |
| 属性克制 | 仅两只怪兽伤害计算时适用，克制方攻守 ×2，被克制方 ×½ 向上取整到整数。同属性不变。神克制其余六属性；光暗互克、双方 ×2；炎→风→地→水→炎。无属性衍生物无相克；直接攻击没有倍率。 |
| 等价交换 | 表侧效果怪兽攻守 −星数×100，无效果怪兽 +星数×100。效果无效／变为无效果也适用无效果分支；等级以当前值计算，超量取阶级、连接取连接值。数值最低 0。 |
| 计划经济 | 每位玩家自己回合最多 10 次、对方回合最多 3 次卡片／效果发动。灵摆刻度和强制诱发计入，攻击、召唤手续和盖放不计。发动已经提交即计数，之后被无效也不退回；未完成的选择和非法操作不计。 |
| 多抽多补 | 通常抽卡为当前全局回合数 −1。第二回合抽 1，第三回合抽 2。先攻第一回合仍无通常抽卡。 |
| 苦肉 | 每位玩家每个回合可支付当前 LP 一半（向下取整）抽 1。自由行动及双方响应窗口均可使用，不入连锁。LP 至少 2，卡组须有卡。 |
| 深渊之拥 | 该玩家墓地每张卡使自己表侧怪兽攻守 −50，实时计算，最低 0。 |
| 原初洪流 | 无效果怪兽攻击力 +1500、不受对方卡效果影响。效果无效／变为无效果者以及无效果衍生物包含在内。 |
| 双核超频 | 通常抽 2；额外获得 1 次通常召唤或盖放。原有卡片授予的额外召唤仍受各自条件约束。 |
| 尊卑有别 | 表侧怪兽不受比自己星数低的怪兽效果影响，魔陷不受此限制。超量／连接使用召唤时素材星数合计，取除素材不会降低；连接作为素材按连接值计算。无法追溯素材时使用阶级／连接值。 |
| 命运轮盘 | 从第二回合开始，在通常抽卡阶段处理后掷骰。1：抽 1 并重掷；2：失去回合数×1000 LP 的规则伤害；3：选择场上卡破坏；4：选择场上卡除外；5：回复回合数×1000 LP；6：任选墓地卡回所有者卡组，额外怪兽回额外。无候选则跳过该结果。规则破坏和伤害不受卡片保护影响。 |
| 狂欢连锁 | 连锁长度至少 3 时，每个成功处理的效果使其控制者回复 500，整条连锁结束后每个成功处理效果再奖励 1 张抽卡。同一玩家处理多个效果会得到多份奖励。无效或因来源条件缺失未处理的环不奖励。 |
| 厌恶真空 | 每位玩家每回合一次，手牌从有到无时登记，在当前原子操作后的任务处理点抽 2。触发点之后又得到手牌不会取消奖励。 |
| 魔导回响 | 通常／速攻魔法发动处理后原位盖放，该实体下次使用后除外；回到手牌再用仍算下次。发动被无效不回响。速攻魔法重新盖放当回合仍不能使用。 |
| 当头炮 | 通常／特殊召唤至中央主怪兽区（索引 2）的怪兽攻击力 ×2 至回合结束。默认优先中央；盖放、反转召唤不适用。 |
| 观星？ | 从卡组加入手牌（抽卡除外）每张触发一次，对方公开卡组顶；怪／魔／陷类型相同加入手牌，否则送墓。观星自身不递归触发。 |
| 灵魂解放 | 将送墓的卡改为除外，包括代价、素材、结算后的魔陷和场上的灵摆卡。衍生物仍然消失。 |
| 遗产馈赠 | 表侧怪兽被对方战斗／效果破坏并确实入墓时，其原控制者抽 1；墓地怪兽不能发动效果，墓地效果无效。 |
| 团结之力 | 表侧怪兽攻守 +自己场上表侧怪兽数×400，包括自身和衍生物。 |
| 快速拔枪 | 盖放的通常陷阱、速攻魔法当回合可用。发动条件和响应速度保留；永续／反击陷阱无此特权。 |
| 卷刃 | 战斗破坏怪兽后，胜者攻击力下降受害者原本攻击力一半，奇数向上取整，最低 0，离场重置。 |
| 悬赏令 | 准备阶段对方没有通缉犯时，随机标记其一只怪兽（包括里侧）。破坏者回复 2000 并抽 1；仅送墓、解放或除外不算破坏。标记离场消失。 |
| 天使的施舍 | 通常抽卡改为公开顶 3，选 1 入手，其余送墓。不足 3 张则全部公开；空卡组按无法抽卡判负。选择期间可以存档恢复。 |
| 血祭召唤 | 等级至少 5 的可通常召唤怪兽可支付等级×300 LP，替代全部解放进行通常召唤或盖放。LP 必须大于代价，仍占通常召唤次数。原解放方案保留。 |
| 刚柔并济 | 为需求中「没想好名字」命名。攻击表示不被战斗破坏，战斗伤害照常；守备表示（含里侧）不被卡片效果破坏。 |
| 只是睡着了 | 第 T 回合送墓的卡，在 T+3 回合的结束阶段回所有者卡组并洗牌，额外怪兽回额外。离墓后重新入墓重新计时。 |

法则只改变其明确覆盖的规则，其他卡片的发动条件、区域限制、选择和胜负判定继续由现有引擎执行。项目仍是独立同人规则实现；逐卡的既有近似说明仍见图鉴及年度交接。
