# 扣血与代价归属修复（2026-09-14）

熔岩魔神原先把准备阶段伤害绑在 `golemOwner`（最初召唤者）上，旧回归测试也断言了这个错误结果。现在由当前控制者在自己的准备阶段受到 1000 点效果伤害；控制权变化后随之改变。旧存档中残留的 `golemOwner` 不再参与结算，无需重新开局。

本轮排查了召唤收费、维持代价、控制权变化、离场及装备关联的扣血处理，分别使用实际召唤者、效果发动者、当前控制者或离场前控制者，按卡片效果选择归属。

| 卡片／场景 | 修正后的处理 |
| --- | --- |
| 熔岩魔神 | 当前控制者自己的准备阶段受到 1000 效果伤害；里侧、效果无效、伤害防止分别核查；强制效果不能因关闭可选响应而跳过。 |
| 连锁能量；熔岩魔神、火山女王、拷问巨人 | 从手牌特殊召唤到对方场上时由召唤者支付。衍生物内部暂存于手牌数组不产生费用。多张连锁能量叠加，支付后不重复检查并收取同笔费用。 |
| 解放对方怪兽的召唤手续 | 区分允许解放哪一方的怪兽与实际执行解放的玩家；普通解放代价仍不能使用对方怪兽。费用不足时不消耗祭品或生成衍生物，对方满场时按解放后区域判断。 |
| 上述三只赠送怪兽 | 召唤回合的通常召唤／盖放限制作用于召唤者。 |
| 诅咒纸符 | 装备怪兽被破坏、纸符送墓时，使用怪兽离场前的控制者和原本守备力；支持怪兽被除外、衍生物消失。单纯送墓、纸符提前离场或纸符自身被除外不会造成这笔伤害。 |
| 步向破灭的速攻抽卡、脑开发研究所、风暴召唤师、猛犸僵尸、红尘妖 | 使用移动事件保留的控制者，避免卡片回到持有者墓地后扣错人；相应强制伤害及破坏／送墓条件一并修正。 |
| 恶狂战士 | 作为同调素材送墓后，由进行同调召唤的玩家受到 2000 点伤害；素材被除外时不发动这个墓地效果。 |
| 核心再炼成 | 自己结束阶段关联怪兽被破坏时，按其离场前攻击力对陷阱控制者造成伤害；核查陷阱持有者不同、怪兽控制权转移、对方结束阶段与陷阱无效。 |
| 常春藤壁、梦魇恶魔群的衍生物 | 衍生物被破坏后，即使已消失，也对离场前控制者结算 300／800 点伤害；解放不触发破坏伤害。 |

没有全局把墓地效果改成“离场前控制者”。例如贪食龙（Granadora）的墓地伤害仍按墓地效果发动者处理。专项用例也检查了蘑菇怪人、X-剑士 珀修尔、恶魔棋子维持费、通行税等控制权变化后的结算。
