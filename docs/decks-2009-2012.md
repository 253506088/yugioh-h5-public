# 2009—2012 年度代表构筑

每年三套，共十二套；主卡组均为 **40 张**，额外卡组 **不超过 15 张**，主卡组和额外合计同名不超过三张。卡片的首次 OCG 日期候选不得晚于牌组年份，生成脚本会拒绝越年卡、错误区域和非法张数。

这些是**参考历史战术、按本作当前卡文改编的构筑**，不是赛事原牌表的逐张复刻。项目没有 Side Deck、Match 或历史禁限表切换，不能把这些牌表直接当成某场现实赛事的报名表。

在「新决斗」的「按年度选择预设」中选择 2009、2010、2011、2012，即可看到当年的三套。这个筛选只缩小第一席的牌组列表，对手仍可选择全部预设或保存的自定义构筑。十二套均可复制到工坊、机器人观战或参加竞技场。

## 史料与选择理由

以下页面于 **2026-09-14** 读取。Road of the King 是第三方赛事与环境整理来源，项目不把它标为 KONAMI 官方逐卡认证。

- [2009 世界赛](https://roadoftheking.com/yu-gi-oh-world-championship-2009/)：冠军 Benjamin Tan Hong Hwee、季军 Roy St. Clair 均为 Blackwing；亚军 Chien Yen Jui 为 Cat Gladiator Beast。因此保留黑羽和猫剑斗，加入同年热门 Cat Synchro，避免两套黑羽重复。
- [2010 世界赛](https://roadoftheking.com/yu-gi-oh-world-championship-2010/)：冠军 Galileo De Obaldia 为 Frog FTK，亚军 Vincent Paglia 为 Blackwing，季军 Kuwano Kei 为 Herald of Perfection。三种体系不同，全部采用。
- [2011 世界赛](https://roadoftheking.com/yu-gi-oh-world-championship-2011/)：冠军 Ogawa Takashi 为 Agent Fairy，亚军 Murakoshi Kei、季军 Galileo De Obaldia 均为 Junk Doppel。保留一套废二，第三套采用当年热门且进入该届八强的 Six Samurai。
- [2012 世界赛](https://roadoftheking.com/yu-gi-oh-world-championship-2012/)：前三 Saito Akikazu、Stefano Memoli、Joshua Schmidt，以及第四名均为 Inzektor。因此只保留一套甲虫装机，另选发条、水精鳞海皇。
- [OCG 2008.03—2012.09 五年回顾](https://roadoftheking.com/ocg-2008-03-ocg-2012-09-a-quinquennium-in-review/)：说明猫同调、2011 六武／废二／代行及 2012 甲虫装机、海皇水精鳞、发条的环境位置，补充重复名次之外的全年代表选择。
- [OCG 2012.03 环境](https://roadoftheking.com/ocg-2012-03-metagame/)及 [OCG 2012.09 环境](https://roadoftheking.com/ocg-2012-09-metagame/)：支持发条与水精鳞的代表性。后一个统计区间延伸到 **2013-02-28**，本项目只据此研究体系，选卡仍严格截止 **2012-12-31 的 OCG 候选日期**。

没有把来源中缺失的牌表图片猜成完整原表。冠军／亚军／季军只是体系选取依据，具体改编牌表以提交的 JSON 为准。

## 当前卡文与历史的区别

- 救援猫、三眼怪、光枪龙、御用守护者、未来融合等使用保存的当前文本及本作实现。2009 的“猫僧同调”没有按旧版光枪龙与过早埋葬的无限循环放宽规则。
- 蛙炮循环保留真实的除外、复活、解放与每次400伤害。机器人使用本作通用战术，并不保证每次起手都能找到现实比赛里的最优 FTK 路线。
- 黑羽宝札、强欲而谦虚之壶等抽卡牌会限制特殊召唤，不能先展开后无视代价发动。主卡组未强行加入不属于当年 OCG 候选范围的后续支援。
- 发条的“表侧存在期间一次”与通常的每回合一次分开处理；离场／盖放重置会影响可用动作。
- 水精鳞未加入下一年 OCG 才出现的后续展开卡。海皇须由水属性怪兽效果的送墓代价触发，普通堆墓和这类代价分开记录。
- 多个同期强卡的张数属于全年玩法改编，不宣称同时符合某一天的历史禁限表。

## 可复现来源

牌表及来源元数据：`data/decks-2009-2012.json`。生成命令：

```powershell
npm.cmd run decks:chronicle
```

生成 `src/chronicle-decks.js` 和 `src/i18n-chronicle.js`；Node 与浏览器均加载这些文件，避免两份牌表漂移。研究网页副本留在忽略的 `output/rollout-2009-2012/`。运行与对战结果见 [验证记录](verification-2009-2012.md)。
