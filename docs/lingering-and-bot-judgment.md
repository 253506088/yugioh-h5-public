# 生效中的效果、手坑与反击陷阱判断

本批对应 2026-09-21《优化需求 1》的前三项。规则引擎没有新增任何裁定；第 1 项只做观察与展示，第 2、3 项只调整机器人的选择，玩家仍可执行任何合法操作。

## 1. 战斗中看到仍在生效的效果

一时休战的伤害归零、强欲而谦虚之壶的不能特殊召唤、和睦的使者、效果遮蒙者的效果无效等，在结算完毕后并不留在场上，此前只能翻决斗记录回忆。现在：

- **双方信息栏**（LP 右侧）显示"生效中"芯片：效果文字、来源卡、剩余期限（本回合／至第 N 回合／持续中）。每栏最多显示 3 枚，多出的以 `+N` 折叠。
- 卡片级别的效果（效果无效、不能攻击、不会被破坏等）显示在**受影响怪兽控制者**的栏上，并标注卡名；被无效的表侧怪兽在场上直接带"无效"角标。
- 决斗场顶部的 `◎` 按钮显示总数；点击芯片或按钮打开「生效中的效果」窗口，按机器人 B／机器人 A（或对方／你）分组列出全部条目、来源卡图、来源卡文字，卡图可直接打开卡片详情。
- 双方的条目都会展示：观战模式看到两台机器人的全部效果，普通对局也同样看到对方栏上的限制。
- 中／英／日切换时芯片、窗口与角标同步翻译；切换语言时已打开的窗口原地重绘。
- 手机竖屏只保留第一枚芯片与 `+N`，横屏缩小高度；桌面一屏战斗的信息栏高度不变。

### 实现方式

`src/lingering.js` 在每个连锁环结算前后比较三类标记：玩家标记（`preventDamageUntil`、`wabokuTurn`、`eraLocks.*`、`locks[]` 等）、决斗级标记（`coldWaveUntil`、`noSummonUntil` 等）以及场上卡片标记（`eraNegatedUntil`、`effectNegated`、`positionLockedUntil` 等）。结算后新出现并且仍在生效的标记记入 `state.lingering`，同时保存来源卡、发动者、连锁编号。固有效果（电子龙自登场之类不入连锁的效果）走 `lingering-diff` 任务，同样归因。

每回合开始由引擎调用 `prune()` 清掉已过期条目；读取时再次核对当前标记与期限，条目不会比规则本身多活一个回合。`usedTurn`、`eraSpecialTurn`、`summonedThisTurn` 这类"记账"字段列在忽略名单里，不当作效果展示。

标签表按标记名维护三语文字；遇到没有登记的新标记，回退为「「卡名」的效果生效中」并带期限，不会遗漏。`state.lingering` 只是观察记录：不参与任何规则判断，AI 推演复制引擎时把它列入忽略键，旧存档缺少该字段时自动补空数组，规则本身不受影响。

PVP 由服务器投影公开列表 `state.activeEffects`，里侧卡的身份按观看者可见性隐藏，客户端复用同一套展示。

## 2. 手坑不再被召唤到场上

效果遮蒙者、战斗消失者、增殖的 G 这类只在手牌发动的怪兽，此前会因为"有怪兽总比没有好"被 0 攻召唤或盖放上场，白白浪费。

`src/ai-tactics.js` 新增 `handTrapBias`：满足 **只有手牌一个发动区域、快速效果或非主阶效果、攻击力不超过 1200** 的怪兽视为手坑，通常召唤与盖放一律扣 1,500 分，通常足以让机器人改为进入战斗或结束回合。两种例外保留：

- **作为素材立即可用**：召唤后额外卡组马上出现新的同调／超量／连接选项（例如效果遮蒙者作为调整），保持原分数并略加奖励。
- **最后的墙**：自己场上没有怪兽，对方公开战力足以直接致死，而且这张卡的手牌效果不能从手牌阻止本次攻击时，允许里侧盖放。战斗消失者自己就能从手牌阻止直接攻击，所以不会被当作墙。

自我特殊召唤型的手牌诱发（影蜥蜴等）与普通的低攻怪兽不受影响，评分与以前一致。

## 3. 反击陷阱不再"亏本"发动

图 2 的场景：A 后场只有一张神之宣告，B 发动大风暴，A 支付一半 LP 无效大风暴，可无论如何神之宣告都要进墓地。

`negationWorth` 在对方发动效果或宣言召唤、我方拥有**需要支付 LP 或额外卡片**的响应时，用现有的推演器分别模拟"放弃"与"发动"两条分支，比较之后的局面价值（场面评估 + 我方存活的表侧后场 + 对方后场与手牌的削减 − 支付的 LP）。只有发动后的局面更好，或能避免直接落败，才保留发动；发动反而让自己进入对方公开战力的致死范围时同样放弃。

验证过的判断：

| 场景 | 决定 |
| --- | --- |
| 神之宣告单独在后场，对方大风暴 | 放弃，不付 4,000 LP |
| 后场有技能抽取、圣防、激流葬时对方大风暴 | 发动，保住其余三张 |
| 己方青眼白龙在场，对方黑洞 | 发动 |
| 对方旋风只指向神之宣告本身 | 放弃 |
| 对方上级召唤 2,500 攻怪兽 | 发动 |
| 对方通常召唤 500 攻怪兽 | 放弃 |

不需要代价的响应（效果遮蒙者、无代价的普通陷阱）不进入这个判断；机器人在自己回合发动效果的既有判断也不变。这是 AI 策略，`act()` 仍接受玩家的任何合法发动。

## 顺带修正的三个既有问题

回归模拟暴露了三个与本次改动无关、但会让机器人对局卡死或报错的旧问题，已一并修复并加入 `tests/simulation-fixes.test.cjs`：

- **巨大化海啸把自己也弹回手牌**：导致青蛙牌组用巨大化海啸与大量驱动无限循环，直到 3,000 步保护。现在只返回其他魔法·陷阱，场上没有其他卡时不能发动。
- **魔导书之师复制无法处理的魔导书**：墓地只有恶灵魔导书而没有被除外的魔导书时，选择复制后没有合法对象，赛事报错「现在不能发动这个效果，或没有合法的目标」。现在只提供当前能够实际处理的魔导书作为复制候选。
- **机器人选择付不起代价的响应**：假面英雄 暗法在场时，欧尼斯特作为代价不能实际送去墓地，但响应窗口仍然列出它，机器人选择后整局报错。新增 `aiCanCommit`：机器人回答响应窗口或可选诱发前，先在复制的引擎上确认该操作能够提交，失败则改选下一项或放弃。检查不改变实局状态与随机序列。

## 边界

- 展示依赖标记名称模式（`*Turn`、`*Until`、`*Lock`、`eraLocks`、`locks`）。极少数旧卡把限制写在自定义对象里且不带这些后缀时不会出现在列表中；出现新标记时只需在 `lingering.js` 的标签表加一行。
- 持续魔法／陷阱和装备卡本身在场上可见，不重复列出。
- 反击陷阱判断只比较当前公开信息，对方未公开的手牌不计入；推演不确定（随机、需要对方选择）时保留原来的发动。
