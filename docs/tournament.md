# 死斗竞技场

从首页点击 **死斗竞技场**，或在「新的决斗」中选择「机器人淘汰赛」。默认 16 人，支持 **2–64 人**；可使用任意整数人数。也可以收藏 `index.html#arena`，直接进入竞技场。

## 组建阵容

- **随机填满席位**：从全部本地卡组、仅预设或仅自定义卡组中抽取。工坊保存的合法自定义卡组会自动加入本地名单。
- **逐个指定**：每个 BOT 席位都有独立的卡组选择器，可以指定所有参赛卡组。
- **重复卡组**：默认允许，即使本地卡组多于参赛人数也能重复。同名机器人自动编号为「1号」「2号」等。不允许重复时，人数不能超过随机卡组池数量，手动名单也需保持不重复。
- **打乱签位**：只调整已有阵容的顺序。对阵预览可以在开赛前查看两两配对与轮空安排。
- **更多设置**：可指定抽签种子与机器人难度。相同种子和相同卡组池顺序可复现随机名单；赛事中的每一场猜拳、洗牌和同分裁定都有独立种子。

开赛时保存完整卡组构筑。之后编辑或删除原自定义卡组，不会改变本届参赛机器人的卡组；赛事也不会替换普通决斗存档。

## 调度与晋级

这是单败淘汰赛，胜者进入下一轮。非 2 的幂人数会均匀分配轮空，不会产生无人对战的空场次。N 人赛事需要 N−1 场胜负明确的比赛决出冠军；轮空不计为胜场。

比赛中可以随时切换：

| 设置 | 行为 |
| --- | --- |
| 串行 | 一场接一场进行 |
| 并行 2 / 4 / 8 场 | 多个独立局面同时推进，点击任一场进入观战 |
| 沉浸 / 快速 / 极速 | 调整行动推进节奏 |
| 暂停赛事 | 所有场次停在当前局面，继续后原地恢复 |

从并行切到串行时，多出的场次保留局面并等待调度。上一轮全部有结果后，下一轮自动开始。调度顺序不参与洗牌和决策随机数，同一阵容与种子的比赛结果不因串行／并行切换改变。

双向晋级图以决赛为中心，显示待开赛、进行中、晋级与淘汰情况。支持缩放、滚动、定位决赛；「全部比赛与录像」可以筛选场次，「选手榜」展示胜场、淘汰状态与累计伤害。下方直播台显示各场 LP、回合与观战入口。

## 观战与录像

点击晋级图或直播台上的场次，进入实际决斗棋盘。双方手牌和盖牌全部公开，卡片详情、墓地、额外卡组、决斗记录及连锁记录仍可查看。

- 顶部下拉框切换比赛；有重赛时可选择第几局。
- 进度条回看任意已录制位置，回合下拉框跳到指定回合。
- 支持上一步、下一步、暂停／播放，以及 0.5×、1×、2×、4×、8×播放。
- **回到直播**跳到这场比赛的最新局面。
- `Space` 暂停／播放，`←` / `→` 或 `N` 逐步查看；输入框和下拉框保留自身键盘操作。
- **暂停回看**只暂停观看进度，赛事继续推进。需要暂停所有比赛时，返回赛事全景点击「暂停赛事」。

录像保存起始局面、每一步实际操作、对应随机状态与最终局面。回放不重新请求 AI 决策，也不会影响赛事引擎或普通决斗。中途刷新后可继续观看已经录制的部分；完赛后所有场次仍可回看。

## 平局与异常

- 机器人猜拳决定每局先后手，双方均使用正常随机起手。
- 正常平局最多重赛 2 次，每局录像分别保留。
- 单局超过 **160 回合**或达到 **2,400 步**，或连续重赛后仍平局，依次按 **LP → 累计造成伤害 → 赛前种子抽签**决定晋级。界面明确标记「赛制裁定」，录像保留实际局面，不伪造 LP 归零或引擎胜利。
- AI／规则异常保留发生问题的录像；其余同轮场次继续。点击「保留录像并重赛」重新开局，不会把异常自动记为某方获胜。

这些保护是本作淘汰赛规则，并非官方竞技赛事的裁定规则。

## 存档与备份

赛事独立保存在当前浏览器的 IndexedDB 中，约每 1.8 秒保存一次；暂停、切换赛事和离开页面时也会尝试保存。刷新后恢复为暂停状态，手动继续即可。普通决斗、自定义卡组与工坊草稿使用原来的独立存档。

「赛事档案」保留各届赛事。新建赛事会暂停并保存上一届。导出 JSON 包含整届比赛、参赛构筑和所有录像，可以重新导入；导入作为另一份赛事副本保存。清理站点数据或更换浏览器不会自动迁移存档，建议导出重要赛事。若浏览器拒绝保存，界面会提示导出备份，本次页面内的未保存赛事也保留在赛事档案中。

直接打开 HTML 与通过本地服务器访问可能属于不同的浏览器存储位置；跨入口请通过赛事 JSON 导入导出。

## 开发与验证

```powershell
npm.cmd run build
npm.cmd run build:no-art
npm.cmd test
npm.cmd run test:browser
npm.cmd run test:experience
npm.cmd run test:tournament
node tests/tournament-simulation.cjs
```

`test:tournament` 包含赛事核心和真实浏览器流程。浏览器测试默认本机 Edge，可用 `DUEL_BROWSER` 指定浏览器程序，以 `DUEL_TOURNAMENT_HTML` 指定待验证成品。压力脚本执行两届 64 人赛事，检查全部 126 场晋级、存档恢复和决赛录像重放。

- `src/tournament.js`：抽签、淘汰树、并行调度、卡组快照、裁定与录像游标。
- `src/tournament-storage.js`：独立赛事数据库与档案索引。
- `src/tournament-ui.js`、`src/tournament.css`：阵容配置、双向晋级图、赛事档案和观看控制。
- `src/game-v2.js`：把只读观看局面接入原有棋盘，观看结束后恢复原普通对局。
- `output/tournament-browser/`：浏览器报告与桌面／手机截图。
- `output/tournament-simulation/report.json`：64 人压力测试报告。

所有功能均编入根目录单文件 `index.html`，不需要额外服务或运行时逻辑依赖。
