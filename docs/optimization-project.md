## 维护边界

1. 后台运行要求页面和浏览器进程仍存活；系统休眠、浏览器冻结／丢弃标签页时无法执行JavaScript。Worker不可用时回退普通计时器，可能受浏览器节流影响。
2. 拟似空间复制已登记的场地操作和通用持续规则；这不是对所有场地独立事件及全部组合的官方裁定认证。仅在“卡片发动时”适用的操作不因复制再次执行。新增年度场地后，复制注册器必须位于全部效果分册之后。
3. 2017仍有563个pending，本批没有把待实现卡宣称为可用。现有逐卡适配说明继续适用。
4. 正式源码、测试、离线输入、发布HTML和维护文档提交；需求原文、截图、研究、临时修订脚本与验证日志由`.gitignore`中的`/需求文档/`及`/output/`排除。

测试入口：`npm run test:optimization-project`。完整回归及旧浏览器脚本仍可独立执行。报告与截图位于`output/optimization/`，各专项日志位于`output/optimization-*.log`。
