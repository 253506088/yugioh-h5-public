# 2015 年度牌组

本批新增三套不同策略，均可在「新决斗 → 2015」选择。第一、二套保留世界赛原表的 **41 张主卡**与15张额外，第三套为40／15的年末环境代表构筑。牌表和来源见 `data/decks-2015.json`，执行 `npm run decks:chronicle` 重建预设及三语文案。

| 预设 | 来源 | 主要玩法 |
| --- | --- | --- |
| 世界冠军 · 星骑士 | Hiyama Shunsuke，2015 世界冠军 | 天津四检索，织女星／牵牛星展开，冬三角回手，托勒密升阶 |
| 世界亚军 · 影灵衣 | Galileo De Obaldia，2015 世界亚军 | 仪式检索，万华镜送额外素材，三叉龙多区域除外，火冰手与幽鬼兔支援 |
| 年度人气 · 娱乐伙伴娱乐法师 | OCG 2015.10 环境统计中的 EMEm | 丑角与猴子找刻度，龙剑士破坏火布偶展开，同调／四阶超量选择 |

世界赛第三名 Hasegawa Akira 也使用影灵衣，因此第三套按用户要求替换为玩法不同的人气体系。环境文章记录了309次娱乐伙伴娱乐法师上位；这里使用其代表组件组合，**第三套不是某名选手的原始牌表**。

前两套的副卡各15张保存在来源 JSON 中，供复核与手动组卡；本作 BO1 预设使用主卡和额外。当前决斗规则、卡片效果文本及自由构筑限制沿用项目约定，不模拟世界赛当年的全部禁限表与旧裁定。
