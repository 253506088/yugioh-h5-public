## 回归发现与修复

小夜的两目标组合在“纯爱妖精街道”移除不可取对象的候选后仍保留旧组合，机器人会提交非法目标。修复同时过滤候选与合法组合，无组合时禁止发动；实际失败案例32重跑198步后完成并完整重放一致。最终统一重跑的66场全部通过。

VS 的列计算错误地把共享额外怪兽区的物理编号再次当作相对区域名称转换，导致拉岑误认一侧额外区。四个新场景覆盖双方和两个额外区，断言同列怪兽确实被破坏、另一列保留；修复前两项失败，修复后全部通过。

三战发动记录使 AI 把没有实际效果的重复发动判断成“新增收益”。真实状态继续保留记录以供三战判断，仅在 AI 的边际结果比较中排除历史字段；卡利古拉空效果回归与三战实际发动回归均通过。最终整局、赛事与编年quick使用修复后的代码。

修正旧测试残留的78预设断言，以及2022累计筛选误用全库12,522作为分子的问题；通过2022筛选的身份仍为12,003。供应方 Ace★Spades 的规范链接经实际访问确认含Unicode字母，百科检查采用与导入器相同的解码路径约束，保留HTTPS、固定域名和无凭证／查询／片段的限制。

最初回归还暴露本机测试依赖缺失，已按锁文件执行 `npm ci` 恢复。上表只统计完整依赖与最终源码的通过结果，不把此前失败日志或旧HTML检查算入最终验收。

## 方法和边界

年度整局包含五套2023牌各对2016青眼、十二兽交换先后手的20场，以及五套之间有方向的20场交叉对局；再逐条覆盖26种天命。种子为 `202310020 + case`，案例0—65连续，每场第24步恢复JSON存档，终局从初始状态逐动作重放并比较完整快照，没有放宽3000行动上限。

64人赛事种子为 `20231001`，使用五套2023牌和三套2016对照牌。Worker只并行独立场次，使用生产赛事实现；63场逐动作重放一致，整项赛事存档恢复成功，未使用行动上限保护结果。57场quick不是全历史预设的完整配对矩阵。

七年度浏览器打开同一正式单HTML并阻断外部HTTP，验证真实操作、代价／目标选择、三语、年度筛选和390px布局。2023包含深渊兽召唤、VS展示、纯爱妖精检索、湍流盖四、迪亚贝尔斯塔尔代价，并在独立 `isMobile:true`、`hasTouch:true` 环境用触屏操作完成深渊兽召唤。桌面和触屏截图已视觉检查；这是Edge/Chromium模拟环境，不冒充实体手机或其他浏览器内核。AI导入使用模拟模型响应与本地代理，未调用外部付费模型。

五套牌均为有同期来源的全年代表改编，各40／15／15，不冒充选手原表或某季度禁限表。2023世界赛两位四强并列，VS路线未被虚构为独立季军。详细来源与玩法见 [五套构筑](decks-2023.md)，逐卡状态见 [覆盖表](coverage-2023.md)。

供应方首次OCG日期尚未完成全部官方产品交叉核验。pending身份继续禁止进入有效对战构筑。发布脚本使用本地gzip解压，需要支持DecompressionStream；构建器拒绝达到100MiB的文件。卡片数据可从正式输入离线重建；本次逐字节成品重建使用现有本机媒体，没有媒体缓存的克隆会按构建器设计采用流媒体地址。

## 复现

$env:Path = 'C:\nvm\v22.17.0;' + $env:Path
npm.cmd ci --no-audit --no-fund
npm.cmd run cards:import
npm.cmd run locales:sync
npm.cmd run cards:catalog
npm.cmd run decks:chronicle
npm.cmd run cards:coverage:2023
npm.cmd run test:2023
$env:DUEL_TEST_CONCURRENCY = '4'
npm.cmd test
Remove-Item Env:DUEL_TEST_CONCURRENCY
